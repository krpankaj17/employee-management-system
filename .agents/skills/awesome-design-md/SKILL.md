# awesome-design-md Skill

This skill provides direct access to analyzed, production-grade DESIGN.md design system specifications from 74+ world-class technology companies and developer tools.

## Supported Design Languages
- **Linear.app** (`design-md/linear.app/DESIGN.md`): Deep black canvas (`#010102`), charcoal panels (`#0F1011`), hairline borders (`#23252A`), signature lavender accent (`#5E6AD2`), measured negative tracking (`-0.4px`).
- **Stripe** (`design-md/stripe/DESIGN.md`): Soft luminous canvas (`#F6F9FC`), pure white card surfaces (`#FFFFFF`), deep navy ink (`#0D253D`), electric indigo primary button (`#533AFD`), hairlines (`#E3E8EE`), tabular numbers (`tnum`).
- **Resend** (`design-md/resend/DESIGN.md`): True black (`#000000`), dark charcoal (`#0A0A0C`), hairline 1px borders (`rgba(255,255,255,0.06)`), crisp off-white text (`#FCFDFF`), strict 12px container radii, editorial typography.
- **Raycast** (`design-md/raycast/DESIGN.md`): Command-bar density, crimson/ruby accents, keyboard-first navigation chips.
- **Supabase** (`design-md/supabase/DESIGN.md`): Emerald brand green (`#3ECF8E`), dark zinc surfaces, high-density database table layouts.
- **Vercel** (`design-md/vercel/DESIGN.md`): Stark monochrome, crisp geometric badges, zero gradient noise, pure functional clarity.

## How to Apply
1. Read the target brand's `DESIGN.md` in `.agents/skills/awesome-design-md/design-md/<brand>/DESIGN.md`.
2. Extract exact hex codes, border rules, typography tracking, and radii.
3. Apply to component CSS / Tailwind classes without adding ungrounded neon glows or heavy decorative blurs.
